# Major Project Scope

## Core Module
AI-based fake/suspicious review classification.

## Advanced Modules
1. Explainable risk signals
2. Product-level suspicious-review ratio
3. Reviewer history
4. Moderation workflow
5. Admin analytics
6. Authentication and authorization
7. Database persistence
8. Model retraining workflow
9. REST API
10. Responsive dashboard

## Future Research
A strong final-year version can compare:
- TF-IDF + Logistic Regression
- TF-IDF + SVM
- Random Forest
- DistilBERT/BERT
- Ensemble scoring

Behavioral features can include:
- Review frequency
- Time burst
- Duplicate text
- Rating deviation
- Reviewer-product relationship
- Verified purchase flag
- Sentiment-rating mismatch

## Suggested Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion Matrix

For fake-review detection, precision and recall are generally more informative than accuracy alone.
